# Kubernetes Sentiment App (учебный проект)

Этот репозиторий содержит учебный проект (экзамен) по дисциплине **«Оркестрация и контейнеризация»**:
контейнерное Java‑приложение для анализа тональности текста, развёрнутое в Minikube с Ingress, HPA и мониторингом Prometheus + Grafana.

## Документы

- Отчёт‑методичка: `Итоговый проект. Разработка и развертывание ИИ-приложения в Kubernetes.md`

## Структура

- `app/` — исходники Java и Dockerfile
- `k8s/` — Kubernetes манифесты
- `screenshots/` — скриншоты шагов (вставляются в отчёт)
